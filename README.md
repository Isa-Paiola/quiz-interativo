# Quiz Interativo

Um aplicativo web de **quiz interativo**, desenvolvido como projeto acadêmico, que permite ao usuário responder perguntas e visualizar seu resultado final de maneira simples e dinâmica.

## 🚀 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Isa-Paiola/quiz-interativo.git
   ```
2. **Acesse a pasta do projeto:**
 ```bash
cd quiz-interativo
```
3. **Abra o arquivo index.html diretamente no navegador**
(clicando duas vezes ou arrastando para uma aba do navegador).
- ⚠️ O projeto não requer dependências, instalação adicional ou servidor local.


## 📌 Funcionalidades
- Sistema de perguntas de múltipla escolha
- Contagem automática de respostas corretas
- Exibição do resultado final
- Layout simples, amigável e intuitivo
